# ai-video-automation
Daily AI landscape Shorts: Cloudflare Workers AI (Flux) -> ffmpeg -> YouTube Data API. Runs on GitHub Actions.
One secret CONFIG_JSON (JSON with CF_ACCOUNT_ID, CF_API_TOKEN, GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, GH_PAT) + YT_REFRESH_TOKEN (set by the auth workflow).
Never commit keys.
